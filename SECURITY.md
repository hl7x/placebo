# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report them privately using GitHub's
[private vulnerability reporting](https://github.com/hl7x/placebo/security/advisories/new)
feature, or by contacting the maintainers directly.

We will acknowledge your report as soon as possible and keep you informed as we
work on a fix.

## Scope

Placebo generates **synthetic** patient data and does not process real PHI. If
you discover a scenario where the tool could inadvertently expose or mishandle
real data, we consider that in scope and want to hear about it.

## Supported Versions

This project is developed on a rolling basis; the latest release on the default
branch is the supported version.
